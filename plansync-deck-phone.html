04 漂移 / DRIFT

任务死绑在版本上——计划一动,它立刻漂移Every task binds to a plan version; the moment the plan moves, the task drifts.

localhost:3001 / task / drift-alert
● 真实产品界面 · 正在执行的任务(v1)被标记漂移 → rebind / cancel / no_impact
任务-版本绑定 Task ↔ version
Bound v1 · Active v2——version mismatch 就是漂移的支点。
严重度看交付物 diff Severity = deliverable diff
删除/重写绑定的交付物 = breaking = HIGH;改 goal / 描述等 prose 不触发。正在执行的 run 会被额外硬暂停。
三种处置 Resolve, don't ignore
Rebind 对齐新版本续跑 · No Impact 不受影响 · Cancel 释放。必须人来选。
05 Live Demo · The Money Shot

计划在脚下变了,agent 想交也交不了The plan shifts underfoot — and the agent literally cannot finish stale work.

scripts/demo/drift-interrupt.sh
▶ PHASE 2 · alice 激活 v2(移除 bob 正在做的交付物 pay/card-form)
activate v2 → {version:2, status:"active"}

▶ PHASE 3 · THE MONEY SHOT
drift → {severity:"high", executionGate:"drift_high"}
bob 的 run → 引擎自动暂停 (running → paused)

>> bob 不知情,照常发心跳:
✗ RUN_PAUSED "a newer plan version superseded this run"

>> bob 强行 complete:
✗ RUN_PAUSED "Cannot complete a paused run."
"The agent literally
cannot finish
stale work." 不是提醒,不是告警——是服务端物理上拒绝一次过时的完成。
这个判定在服务端 (L1),不在 agent 机器上。所以换个会话、换个 agent 来问,得到的还是同一个"拒绝"——跨会话的一致,是服务端强制的天然结果。
bob 之后任何一次 PlanSync 调用都会被 MCP 预检短路成 RUN_ABORTED,直到漂移被解决。可一键复现:drift-interrupt.sh。
06 强制 / ENFORCEMENT

刚才那个"交不了",由三层强制兜底——并诚实说清边界Three enforcement layers behind that refusal — and we're honest about each one's limits.

层在哪运行 · Where挡住什么 · Blocks防篡改? · Tamper-proof
L1服务端 (API + MCP)把漂移的 run 记成 complete;对暂停中的 run 发心跳✓ 是 — 跑在服务端
L2客户端 (Claude Code)闸门设上后的「下一次工具调用」——mid-session 硬中断△ 否 — 跑在 agent 机器上
L3CI (GitHub Action)合并 PR:关联任务 HIGH 漂移 / 超出交付物范围✓ 是 — 跑在 CI
硬保证 · Hard guarantee · L1 在服务端:agent 在自己机器上能改任何东西,仍无法让服务器接受一次漂移的完成。这条不可绕过。
诚实边界 · Honest boundary · L2 是客户端 hook,本质防君子不防对抗者。敢讲清这一点,才是真可信——它由 L1+L3 兜底。
07 证据溯源 / STRICT SOURCING

不信 agent 说"做完了"——要 git 证明Don't trust the agent's "done" — make it prove it with git.

声明 ≠ 完成:agent 报 done,服务端去 git 核 require_pr_merged / require_commits_on_branch——证据严格 scope 到本次 run,没到就停在 awaiting_evidence
github_push 证据管道:合并/提交事件由 git 侧(HMAC 校验)推送进来,而非 agent 自报
分支独占 + 防降级:run 启动时锁定分支归属,关掉了多条静默绕过路径
为何更值钱 "用事实证明"是"信模型的话"的反面。模型越强越会说漂亮话,ground-truth 校验只会越重要。
